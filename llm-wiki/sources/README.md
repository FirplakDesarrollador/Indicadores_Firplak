# Fuentes de la wiki

Esta carpeta es para documentos externos que el proyecto necesita conservar como fuente primaria: especificaciones aprobadas, contratos, exportaciones de SQL, manuales o decisiones recibidas de terceros.

Reglas:

- Las fuentes son inmutables; no se editan para “arreglar” su contenido.
- Cada fuente incorporada debe enlazarse desde una página de la wiki.
- No guardar secretos, tokens ni credenciales.
- Registrar la ingesta en [`../log.md`](../log.md).

El código del repositorio permanece en sus carpetas originales y se referencia mediante enlaces relativos; no se duplica aquí.
