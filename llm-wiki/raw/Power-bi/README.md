# 📊 Power BI (Fuentes para Ingeniería Inversa)

Esta carpeta almacena reportes, plantillas, extracciones de metadatos y modelos de Power BI (`.pbix`, `.pbit`, esquemas DAX/M, JSON) utilizados como fuentes crudas para análisis e ingeniería inversa de indicadores.

> **Nota**: Las fuentes originales son inmutables. Los análisis, esquemas y síntesis resultantes se documentan en `wiki/`.
