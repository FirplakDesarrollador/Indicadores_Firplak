# 🧪 Síntesis y Respuestas Compuestas (wiki/synthesis/)

En este directorio se archivan las respuestas de alto valor generadas a partir de consultas analíticas sobre el wiki (*Compounding*).

Cada síntesis debe:
1. Tener frontmatter con `id`, `title`, `type: synthesis`, `tags`, `sources: [...]`, `last_updated`.
2. Registrarse en la tabla de síntesis de [[index]].
3. Anotarse en [[log]] con `## [AAAA-MM-DD] query | Título`.
